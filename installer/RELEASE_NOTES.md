## Download

| System | File | How to install |
| --- | --- | --- |
| **Windows 10 / 11** (64-bit) | `GestureRotary-…-Windows-Setup.exe` | Run it. No administrator rights needed. If SmartScreen appears: *More info → Run anyway*. |
| Windows, no install | `GestureRotary-…-Windows-Portable.zip` | Unzip anywhere and run `Gesture Rotary.exe`. |
| **macOS 14+** (Apple silicon: M1 or later) | `GestureRotary-…-macOS.dmg` | Open it and drag **Gesture Rotary** to **Applications**. The first time, right-click the app → **Open** (or *System Settings → Privacy & Security → Open Anyway*). |
| **Linux** (x86-64, glibc 2.34+: Ubuntu 22.04+, Fedora 35+…) | `GestureRotary-…-Linux-x86_64.tar.gz` | `tar xzf GestureRotary-*.tar.gz && cd GestureRotary-*/ && ./install.sh` |

Open the rotary with **Ctrl + Alt + Space** (Mac: **⌃⌥Space**), by clicking the notch at the top of the screen,
or by raising your hand to the camera.

On a Mac, allow **Camera** when asked. The first time an item presses a keyboard shortcut, also allow
Gesture Rotary under **System Settings → Privacy & Security → Accessibility**.

On Linux, if hand tracking doesn't start: `sudo apt install libgles2 libegl1` (Fedora: `libglvnd-gles libglvnd-egl`).

`SHA256SUMS.txt` lists every file's checksum.
